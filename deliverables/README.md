# P2 Knowledge Base — Deliverables

> The published, consumable outputs of the P2 Knowledge Base.

New here? Start from the [repository root README](../README.md).

- **[`documents/`](documents/)** — the released PDF manuals, with a catalog of descriptions and direct download links.
- **[`ai/`](ai/)** — the AI-consumable knowledge base: structured P2 YAML plus its search index, served by the [P2 Knowledge Base MCP](https://github.com/ironsheep/P2-Knowledge-Base-MCP).
- **[`ai-reference/`](ai-reference/)** — guides for using the knowledge base with AI assistants without the MCP (one-command BOOTSTRAP, usage patterns).
- **[`developer-docs/`](developer-docs/)** — developer guidance, including the Claude Code privacy guide for P2 developers.
