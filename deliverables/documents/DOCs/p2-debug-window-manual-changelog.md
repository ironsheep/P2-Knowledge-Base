# P2 Debug Window Manual — Change Log

## v1.0.0 (2026-06-16)

**Initial release for community review** — the complete guide to the Propeller 2's nine DEBUG display windows.

### Added

- **The nine DEBUG display windows**, a chapter each: TERM, BITMAP, PLOT, LOGIC, SCOPE, SCOPE_XY, FFT, SPECTRO, and MIDI — every directive with its parameters, ranges, and defaults.
- **Foundation chapters**: the create-by-name / feed-by-name model, the feed-stream element model, and a no-hardware setup with `pnut_ts` and `pnut_term_ts`.
- **A worked, software-only example in every window chapter** — thermal heatmap, PID strip-chart, glitch capture, motor run-up, and more — each with a "where you'd use this" guide.
- **Integration chapters**: packed-data high-rate transfer, multiple windows and PASM debugging, host keyboard and mouse input, and live control and status panels.
- **Downloadable example library** (source ZIP): 32 compile-clean Spin2 programs that run on a bare P2 board.
- **Appendices**: command reference and quick-lookup tables across all nine windows.
