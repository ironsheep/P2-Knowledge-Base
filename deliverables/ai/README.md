# AI-Consumable Knowledge Base

Structured, machine-readable P2 knowledge optimized for AI code generation.

- [`P2/`](P2/) — the knowledge base content (PASM2, Spin2, architecture, hardware, application notes, OBEX) as structured YAML.
- `p2kb-index.json` (and its gzipped twin) — the search/lookup index over that content.

Entries in the set cite the Parallax document behind each claim; [`P2/README.md`](P2/README.md) describes the bar this content is held to, and [`P2/CHANGELOG.md`](P2/CHANGELOG.md) leads to the record of what has changed.

Query this through the **[P2 Knowledge Base MCP](https://github.com/ironsheep/P2-Knowledge-Base-MCP)** (recommended), or via the setup in the [repository root README](../../README.md).
