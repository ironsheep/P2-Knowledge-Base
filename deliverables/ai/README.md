# AI-Consumable Knowledge Base

Structured, machine-readable P2 knowledge optimized for AI code generation.

- [`P2/`](P2/) — the knowledge base content (PASM2, Spin2, architecture, hardware, OBEX) as structured YAML.
- `p2kb-index.json` — the search/lookup index over that content.

Query this through the **[P2 Knowledge Base MCP](https://github.com/ironsheep/P2-Knowledge-Base-MCP)** (recommended), or via the setup in the [repository root README](../../README.md).
