1. **Revision framing beyond `basic-io`** (found by the tool-and-standing-checks auditor). Each one
   framed a P2 fact by silicon revision:
   - errata status "Active in Rev C silicon (current production)" ×4 (`augs` ×2, `augd`,
     `setq_block_ops`);
   - GETXACC "ON REV C SILICON";
   - the Goertzel page;
   - `P_ADC_FLOAT` "(Rev C silicon)", which no source attaches;
   - the errata page's title line.

   Fixed in `737de1d2`. Bench citations ("verified on Rev C") stay in `source:`.
2. **Four "(Rev B/C silicon)" framings that the first sweep's grep hid** (found by the fix auditor):
   GETCT (Spin2 and PASM2), `special_registers`, and `serial_loader`. In `serial_loader`, "(A-F were
   FPGA builds)" was also unsourced: neither the P2 Documentation nor the Hardware Manual says it, and
   the auditor searched all of `engineering/ingestion`. Fixed in `dc1f512a`, and audited clean.
3. **Mirror edge cases** (no instance on today's pages):
   - a URL that is a prefix of its link text was skipped;
   - an image-only link's URL glued to the previous word;
   - a URL followed by a full stop was appended twice.

   Fixed in `737de1d2` and `dc1f512a`. Unit cases pass, and `report` still gives 0 changes.
4. **Compile manifest:** GETCT's description changed, so its fingerprint went stale. Refreshed: only
   the fingerprint changed, and the class stays `not-code`.
