# v1.25.5 change-set audit — hub addresses in a Spin2 object and in a PASM-only file

**Range:** `v1.25.4..` the release's content commit, `deliverables/ai/P2/`: 33 files. Compile manifest: fingerprints only.
**Origin:** F-639, from the v1.25.4 live read. Stephen, 2026-11-06: "we need to make sure all of this addressing information gets corrected in this effort." F-564 and F-361 by EF-105, the bench run he asked for.
**Pending gate:** `audit-kb-pending.py --release 1.25.5`, run with the gates.

## Evidence

- **Spin2 v55:** "In Spin2+PASM programs, hub addresses are relative to the start of the object"; "In PASM-only programs, hub addresses are absolute."
- **CP-030:** the encoded values of `##sym`, `##@sym`, `#sym`, `#\sym` and `LONG @sym`, in a top object, a child and a PASM-only control; `@@` rejected in DAT.
- **EF-060:** `##hubsym` failing on silicon.
- **EF-105:** the capture bases and the state after COGSTOP, with both tails of each question seen.

## Findings fixed

Checked by hand at the lines above.

- **Wrong in a Spin2 object:** `inline_pasm.yaml` `with_communication`, `smart-pin-11110`, `smart-pin-11111`. They now receive the address in PTRA from COGINIT. Their `ret` at the end of a started cog goes too: there is nothing to return to.
- **Rule pages:** `spin2-pasm2-integration.yaml` `hub_address_resolution`, `at.yaml`, `labels.yaml`.
- **Bare fragments:** 20 pages carry `hub_symbols`, a one-line pointer. Rewriting them would bury what each page teaches.
- **`execution_modes.yaml`:** `CALL #@hub_func`, `CALL #@cog_func` and `JMP #@main_loop` lose the `@`, which the page does not explain.
- **`cogstop.yaml`:** measured state replaces "not documented", narrowed by pass 3 to what was run: NCO with `P_OE`, its output toggling. The EF-105 heading likewise: cog 0's DIR stays high in the plain-pin arm, so that arm shows the worker's OUT gone and the smart-pin arm shows its DIR gone.
- **`pin-selection.yaml`:** cites EF-105; the text stands.
- **`spin2/concepts/cordic_solver.yaml`:** `recommendation` and "Lower overhead for bulk operations" go: no source states them.

## Removal reasons

Each removed `##@` line is replaced by the COGINIT form above, which v55 documents ("PTRA: Data pointer passed from COGINIT"). No cross-reference was removed.

## What was not checked

The encoded values are image values, not measured runtime addresses, except EF-060's. EF-105 is one board, NCO only, bases in P32..P47. The `PTRA` pattern rests on v55, not on a run of these examples.

## Verdict

**PASS** with the gates of `validate-dod-release.py` at §5.5 and §6c.
