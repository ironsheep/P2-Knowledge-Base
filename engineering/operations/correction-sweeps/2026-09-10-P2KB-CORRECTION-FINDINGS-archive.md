### F-415 — P2AN002 states the CORDIC issue interval as a fixed eight clocks — `RESOLVED-INVALID`

**The reported defect does not exist, and applying the filed repair would have INTRODUCED an error
into a correct manual.** Re-adjudicated 2026-09-10 while working the sweep.

The finding read `(#cogs)` in *"Cogs can start CORDIC operations **every 1/2/4/8/16 (#cogs) clocks**"*
(`silicon-doc-text.txt:184`) as *"depends on how many cogs are **running**."* It does not. The
parenthetical names the **part's cog count** — the interval EQUALS it — and the design is
parameterised over 1/2/4/8/16-cog variants. **The P2X8C4M64P has eight cogs, always**, so *"every
eight clocks"* is exactly right for the only P2 that exists, and it is not runtime-variable.

**Three independent confirmations, all read live:**
- `architecture/cordic.yaml:16` — *"Every 8 clocks per COG (P2X8C4M64P with 8 cogs; Silicon Doc
  verbatim: 'every 1/2/4/8/16 (#cogs) clocks')"*. The KB already carries both halves and reconciles them.
- The companion `p2an002-cordic-for-real-work.yaml` **uses the same eight-clock figure itself**
  (`:35` *"retire one result every eight clocks"*, `:75` *"one result ~every 8 clocks"*), so the
  note and its companion never disagreed — the premise of the filing.
- That companion's own gotcha `:119` adds *"the 55 clocks do not shrink when fewer cogs are
  running"* — i.e. the authority explicitly denies the runtime-dependence the finding asserted.

**What was actually done (P2AN002 v1.0.4):** a precision gain only, matching how the KB annotates it —
the turn is named to the part (*"the interval equals the part's cog count, and the P2X8C4M64P has
eight"*), and the sentence now says neither the eight-clock turn nor the 55-clock latency shrinks when
fewer cogs are running.

*Lesson, and the reason this entry is kept rather than deleted:* this is the fan-out inversion the
project already knows about — a finding generated by reading a source's parenthetical as a variable
when it is a constant. **A finding is a suggestion; the evidence decides.** Had it been applied as
filed, a correct manual would have been made wrong.
