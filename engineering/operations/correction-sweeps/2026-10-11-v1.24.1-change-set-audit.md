Gate review (same auditor): both checks can fail on their class and pass the counter-class; the
allowlist matches leading path segments only (`documentation_source` is still scanned); the
importlib load of the claim-sourcing module runs no audit. Two observations, both false-positive
risks only (a false positive blocks a release and gets read; it cannot let a leak through): the
edition-noun pattern would also match a gating phrase like "Spin2 v47 syntax", and the title+edition
rule's bare-year alternative could match "2000 mA" after a title. Neither occurs in the tree.

- *Served Comments in Shipped Content* — comments that survive the filter, found with `yaml.scan`
  tokens so a `#` inside a literal is value text; flags ids, repo paths, page cites, editions, dates,
  "cross-checked against", commit hashes, change history. Control: 7 fire, 5 do not.

  guide/datasheet", canonical title + edition (imported from `audit-yaml-claim-sourcing.py`), and
  edition stamps attached to a document noun (`vNN's`, `vNN operator table`, `Spin2 vNN symbol
  table`). Reader-resource pointers (`documentation.*`, `resources.*`, `further_reading.*`,
  `source_metadata`) and code leaves are exempt by key path. Control: 11 fire, 14 do not.
