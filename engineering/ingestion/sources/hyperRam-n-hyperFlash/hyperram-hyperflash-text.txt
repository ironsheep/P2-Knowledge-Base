## P2-ES Eval Board HyperRAM &amp; HyperFlash Add-0n (#64004-ES)



This limited edition, 16 MB HyperRAM + 32 MB HyperFlash add-on board is designed specifically for use with the also-limited edition Propeller 2 ES Evaluation Board (#64000-ES).

This accessory features dual 2x6 pass-through sockets that stack on top of two P2-ES Eval Board up to four add-on boards could be installed; one on each side of the P2-ES Eval Board.

The P2-ES Eval Board HyperRAM &amp; HyperFlash Add-on PCB comes fully assembled with surface-mount 16 MB HyperRAM and 32 MB HyperFlash, but supports all combinations of (de-soldering/re-soldering required) or build their own from the open-source design files.

## Features

- Dual hyper memory PCB populated with 16 MB HyperRAM and 32 MB HyperFlash
- Dual 2x6-pin 0.1"passthrough headers connect directly to P2-ES Eval Board
- Optional hyper memory pins available on O.1" pads for user configuration
- PCB supports all combinations of hyper memory modules: 2x HyperRAM, 2x HyperFlash, 2x Dual-HyperRAM/Flash, or 1x HyperRAM with 1x HyperFlash (as sold)

## Specifications

- RAM:16 MB / 128 Mb (16 Mb x 8) Parallel PSRAM
- Flash:32 MB / 256 Mb(32Mbx8) Parallel NOR Flash
- Voltage : +3.3 VDC (supplied by P2-ES Eval Board I/O LDO regulator)
- Maximum clock rate : 100 MHz (200 MB/s) at 3.0 Vcc
- RAM current: 60 mA peak burst, 600 μA standby (CS# = High)
- Flash current: 100 mA peak burst, 25 μA standby (CS# = High)
- Flash Endurance: 100,000 program/erase cycles
- FlashRetention:20-yeardataretention
- Form factor: dual 2x6-pin female passthrough headers with 0.1" spacing
- Mounting hole: hole 2.5 mm (100 mil), pad ring 4.5 mm (180 mil) connected to GND
- Operating temperature range: -40 to +185 °F (-40° to +85° C)
- PCB dimensions: 1.0 x 1.9 in (25.4 x 48.3 mm)

## Feature Descriptions


## 1. HyperBUS Memory A and B

The Parallax Hyper memory add-on board has space for two Hyper memory devices. In this guide, the lower device is referred to as "A" and the upper device is "B".

Each device could be a RAM, Flash or Dual-memory, and the PCB includes various configuration options to support each type of memory (described below).

The initial release of this product is pre-installed with 16MB or HyperRAM for device A, and 32MBofHyperFlashfordeviceB.

## 2.2x6PassthroughHeaders

The 2x6 surface-mount pass-through headers are ready to stack on top of the P2-ES Eval Board, permitting early adopters to test HyperBUS memory devices with the Propeller 2 microcontroller.

The headers are standard 0.1" pitch, making this add-on board a convenient rapid solution for integrationofHyperBusdevicesincustomuserapplications.

See the Pin Definitions and Ratings for a functional description of each connection. Note that the 5V connection is not used by this accessory PCB.

## 3.Optional RES / GNDpads

These optional pads will accept a standard 0.1" pitch header, and provide access to the HyperBUS reset signal.For example, RESET# could be operated by a manual shunt, or connected to some other system reset signal.

In the standard configuration, the shunt resistor below the RES/GND pads is installed across the center-and-right pads, whichkeeps the module held in reset until iO+15 is asserted High.

To use the RES/GND pads instead, remove the shunt resistor and install it across the left-and-center pads instead. This will change the reset operation mode, such that the module willbecomenormallyactive,andeitherlO+15ortheRESpad should be asserted Lowtoreset the HyperBUS memory.

## 5. Memory Type Configuration Resistor B

Located below the "FLS B RAM" label, this two-position shunt resistor is used to set the memory type installed at HyperBUS device B.

HyperRAM and HyperFlash devices use a different pin for CS#.

FLS is "FLASH", RAM is ""RAM"

The pre-installed memory for device B is HyperFlash, and the resistor shunt is pre-set to the correct FLS position.

## 6.+ R C Configuration resistors

Each HyperBuS device has three configuration resistors installed on the right side.

- +10 kΩ pull-up resistor connecting CS#to 3.3V
- R 10 Ω series resistor connecting RWDS to IO+10 (device A) or IO+11 (device B)
- C10 Ω series resistor connecting CK to IO+8 (device A) or IO+9 (device B)

Refer to the schematic linked from the Downloads tab of the 64004-ES product page at www.parallax.com for more information.

## 7. Memory Type Configuration Resistor A

Located above the "FLS A RAM" label, this two position shunt resistor is used to set the memory type installed at HyperBUS device A.

Specifically, this configuration resistor connects the Cs# signal to the appropriate pin, as HyperRAM and HyperFlash devices use a different pin for CS#.

FLS is "FLASH", RAM is "RAM".

The pre-installed memory for device A is HyperRAM, and the resistor shunt is pre-set to the correct RAM position.

## 8. Decoupling capacitors

Each HyperBUS memory has four decoupling capacitors, a 100 nF and a 1 μF for each VccQ pin, as recommended in each HyperBUS memory chip datasheet.

## 9. Mounting hole

The plated mounting hole is attached to the ground plane. See the Module Dimensions section for mounting hole size and position.
