P2 TAQOZ Forth - Boot ROM Interactive Forth Interpreter

This source covers TAQOZ, the Forth interpreter built into the Propeller 2 mask ROM by Peter Jakacki. TAQOZ is one of three interactive interfaces resident in the P2's 16KB boot ROM (alongside the Bootloader and the P2 Monitor) and is accessible from any serial terminal after reset.

What We Know With HIGH Confidence (cross-verified against primary sources we already have):
- TAQOZ lives in the P2's 16KB boot ROM, alongside the Bootloader and Monitor (confirmed by Silicon Doc, Datasheet, rom-booter narrative)
- Entry sequence from serial terminal after reset: type "> " (greater-than + space) then ESC (confirmed by Silicon Doc + Datasheet)
- TAQOZ is a Forth interpreter (Tachyon-derived) authored and maintained by Peter Jakacki (confirmed by central-analysis/who-to-ask)
- Entry is only possible during the early boot window, before flash/SD autorun engages (confirmed by Silicon Doc usage description)

What This Preliminary Research Adds (MEDIUM confidence — needs primary-source verification before publishing):
- ROM build identifier: V1.1, build v33h, dated 2019-02-19 (banner string was quoted from forum)
- ROM word dictionary contains roughly 100-200 active words (pruned subset of Peter's ~500-word dev build)
- TAQOZ ROM is functionally distinct from "TAQOZ Reloaded" — the SD-card-loadable expanded environment
- BACKUP/RESTORE word pair persists user definitions to SPI flash at $F0000
- ROM TAQOZ is copied from ROM into hub RAM to execute (does not run in-place)
- SD card support targets FAT32 only (not exFAT)
- Boot-loader use: TAQOZ can read SD/flash and jump to hub address 0, making it usable as a multi-stage boot mechanism
- Concrete word examples cited: PIN, HZ, ms, MUTE, BACKUP, RESTORE, AUTO, DUMP, @, !, C@, C!, W@, W!, CMOVE, FILL, WYPIN, WRPIN

Distinction From Sibling Tools:
- Bootloader: handles serial/flash/SD boot protocols; not interactive once boot completes
- P2 Monitor: interactive memory inspector/manipulator; entered via "> " + Ctrl+D; example commands like "000-010L" list register RAM in long format
- TAQOZ: interactive Forth environment; entered via "> " + ESC; full programming environment with hardware access

Critical for Understanding:
- TAQOZ provides an interactive "console" for the P2 with no compilation step required
- It's the only built-in interactive PROGRAMMING environment (Monitor inspects/manipulates; TAQOZ programs)
- ROM version is finite and unchangeable — every shipping P2 has identical TAQOZ ROM
- TAQOZ Reloaded (separate SD-loadable system) is the expanded environment Peter actively maintains
- For "what's in ROM" questions, ROM TAQOZ is the answer; for "best TAQOZ experience" questions, Reloaded is the answer
