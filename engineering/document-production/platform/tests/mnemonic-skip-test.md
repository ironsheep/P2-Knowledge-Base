# Chapter 1: skip as English and as the instruction

## Now English (stay lowercase)

CASE-NOUN-1. Each bytecode carries its own skip pattern in the table entry.

CASE-NOUN-2. The skip patterns are 22 bits wide under XBYTE.

CASE-VERB-1. The line after it is add, which three of the four patterns skip, so the call is absolute.

CASE-VERB-2. A bit set to one means the hardware may skip that instruction.

## Already English before this change (controls; stay lowercase)

CASE-CTL-1. You can skip the next three instructions.

CASE-CTL-2. Use a pattern to skip over the unused lines.

## Still the instruction (uppercased)

CASE-NEG-1. Use skip with a pattern in D to cancel instructions in place.

CASE-NEG-2. The skip instruction cancels each instruction whose bit is set.

CASE-NEG-3. Unlike skipf, skip works in hub execution too.

## Written uppercase by the author (left as written)

CASE-UPPER-1. The SKIP pattern here is the instruction's own D operand.
