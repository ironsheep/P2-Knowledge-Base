# P2 Diagnostics Handbook - Changelog

## v0.1.0 (2026-10-13) — Shape Prototype

**The handbook's whole outline, its Symptom Map and one finished chapter, for a decision on its shape.** It is not a release.

### Added

- **Symptom Map**: what you are seeing, in three groups (nothing prints, the run looks stuck, the numbers look wrong), each row sending you to the section that deals with it
- **The outline** of all three parts, Getting Output Out, Supervising a Run and Trusting What You Measure, with every chapter and section named
- **Chapter 2, Staying Inside the Debug Limits**: where to read the compiler's limits, what counts as DEBUG data, moving text out of `debug()`, spending fewer records, compiling less with channels, and keeping a margin, with seven examples that compile
